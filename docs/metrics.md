# Метрики успадкованого модуля — до рефакторингу

Спосіб вимірювання: **вручну** за правилами курсу (автоматичний інструмент не застосовувався).
LOC — кількість рядків без порожніх і без рядків, що містять лише коментар (від сигнатури до закривальної дужки методу).
CC = 1 + кількість точок розгалуження: кожен `if`, `else if`, `case`, `for`, `foreach`, `while`, `catch`,
кожен оператор `&&`, `||`, `??` та кожен тернарний оператор; самостійний `else` не рахується.
Глибина вкладеності — найбільша кількість вкладених `if`/`for`/`foreach` усередині методу.

| Метод | LOC | CC | Глибина вкладеності | Параметрів |
| --- | --- | --- | --- | --- |
| Handle | 80 | 17 | 4 | 11 |
| Preview | 28 | 9 | 2 | 3 |
| DescribeClient | 10 | 3 | 1 | 1 |
| DumpLog | 6 | 2 | 1 | 0 |
| Клас загалом | 130 | — | — | — |

## Розрахунок CC методу Handle (стовпчиком)

| Точка | Кількість |
| --- | --- |
| if (lines != null) | 1 |
| if (lines.Count > 0) | 1 |
| if (state == "new" ...) та оператор \|\| | 2 |
| if (consumerMail != null ...) та оператор && | 2 |
| два цикли for | 2 |
| три перевірки виду клієнта (if / else if / else if) | 3 |
| три перевірки межі знижки if (> 500m) | 3 |
| if (сума < 1000m) | 1 |
| if (sendMail) | 1 |
| **Разом точок розгалуження** | **16** |

CC = 1 + 16 = **17**.

## Додатково

- Відповідальності класу (7): перевірка вхідних даних, арифметика підсумку, знижки, доставка, форматування звіту, журналювання, опис клієнта.
- Дубльованих рядків між Handle і Preview: 18 (Handle, рядки 71–88; Preview, рядки 119–136), рахуючи підряд однакові рядки після нормалізації імен змінних.
- Магічних чисел: 7 різних значень, 25 входжень.
