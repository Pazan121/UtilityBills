# Специфікація функцій — UtilityBills (варіант 14)

Облік показників лічильників і нарахування комунальних платежів. Документ описує, **що** робить застосунок.

## 1.1. Межі системи

| Входить | Свідомо не входить |
| --- | --- |
| облік абонентів і послуги «Електроенергія» (довідники з 60 умовних абонентів у 12 будинках) | оплата через банк, платіжний шлюз |
| внесення показників лічильника з перевіркою | розрахунок за кількома тарифними зонами доби |
| нарахування за сходинками тарифу з пільгою | перерахунок і коригування минулих періодів |
| виставлення рахунку й зміна його стану за таблицею переходів | облік інших послуг (вода, газ): шкала тарифу одна |
| пошук рахунків за абонентом і станом | користувачі, ролі, розмежування прав |
| звіт «нарахування за будинком» | графічний інтерфейс, вебдоступ, база даних |
| збереження рахунків і показників у файлах JSON | конфігурація тарифів без перекомпіляції |

## 1.2. Словник домену

| Термін | Ідентифікатор | Значення |
| --- | --- | --- |
| рахунок | `UtilityBill` | документ нарахування зі станом і рядками |
| рядок рахунку | `UtilityBillLine` | обсяг, тариф і сума за однією сходинкою |
| абонент | `Subscriber` | споживач із адресою будинку й ознакою пільги |
| пільговик | `Subscriber.IsPrivileged` | ознака знижки на першу сходинку |
| комунальна послуга | `UtilityService` | довідник послуг із тарифом |
| показник лічильника | `MeterReading` | значення лічильника на дату |
| споживання | `consumption` | різниця поточного й попереднього показників |
| тариф | `Tariff` | ціна за одиницю на сходинці, грн |
| сходинка тарифу | `TariffStepCharge` | частина споживання з одним тарифом |
| стан рахунку | `BillStatus` | Draft, Issued, Paid, Overdue, Cancelled |
| період нарахування | `UtilityBill.BillingPeriod` | місяць у форматі `рррр-мм` |
| крайня дата оплати | `UtilityBill.DueDate` | дата, після якої рахунок прострочено |
| будинок | `Subscriber.Address` | адреса, за якою групується звіт |
| порушення правила | `DomainRuleException` | помилка предметної області з ідентифікатором правила |
